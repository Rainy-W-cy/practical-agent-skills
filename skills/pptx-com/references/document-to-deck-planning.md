# 材料生成新 PPT 的规划门禁

当用户提供文档、报告、PDF、Markdown、笔记、归纳材料或其他来源，要求基于这些内容生成新的 PPT 时，无论是否提供 `.pptx` 或 `.potx` 模板，都必须先执行本规划流程。

## 强制顺序

```text
读取并分析材料
-> 若用户未提供 plan：形成详细 PPT 规划 Markdown
-> 若用户已提供 plan：审阅其完整性并列出需补充或调整之处
-> 将规划稿交用户确认
-> 用户批准规划后，再确认保存、显示窗口、图片使用与 PDF 导出设置
-> 才可通过 PowerPoint COM 创建 PPTX
```

规划阶段不得先生成 `.pptx`，也不得为了预览而创建临时演示文稿。

## 用户已提供 Plan 的例外

- 用户已经提供可用于制作的 plan 时，不重复生成新的规划文件。
- 先审阅该 plan 是否包含页数、逐页目标、核心结论、具体内容、素材或证据来源、视觉形式，以及仍需确认的制作决策。
- 若 plan 不完整，向用户列出缺口并请求补充或批准必要修订；不得绕过缺口直接生成 PPTX。
- 若 plan 足够完整，明确说明将以该 plan 作为制作依据，并在用户确认后进入写入设置确认。

## 规划文件位置

- 用户已指定输出目录时，保存为该目录下的 `<主题>_ppt_plan.md`。
- 用户尚未指定输出目录时，保存到当前工作区。
- 写入规划文件本身应先说明目标路径与拟写入内容，因为它属于新的输出文件。

## 文档分析内容

规划稿首先概括：

- 材料主题、来源范围和可用内容。
- 外部来源信息：若材料来自 Notion、网页、URL 或其他链接，记录页面标题、URL、访问日期、相关章节或块；默认只读，不写回来源页面。
- 目标受众、汇报场景与预期效果；无法从材料判断时标注待确认。
- 核心论点、关键结论与支持材料。
- 可复用的数字、图表、图片、案例、引用或证据。
- 对论文、预印本、文献汇报、组会分享或学术答辩任务，列出关键图、关键表、方法框图、结果图、消融图、架构 block 或需要解释的局部区域，并为每一项标注处理方式：原图引用、截图/裁剪关键 block、PPT 重画/复现、解释性简化重画、或跳过并说明理由。
- 插入或裁剪论文原图、截图、证据图或关键 block 时，规划稿必须记录来源标注：论文标题/作者/年份、figure/table 编号、页码或章节，以及该视觉是原图、裁剪、复现还是解释性简化。
- 适合删减、压缩、拆分或转化为视觉表达的内容。
- 缺少依据、不能直接进入 PPT 的陈述，以及需用户补充的材料。

## 整体方案

规划稿应提出：

- 建议标题。
- 建议总页数和章节结构。
- 建议汇报时长；无法合理估计时标注需确认。
- 页面比例与输出级别：快速草稿或正式演示文稿。
- 视觉风格、配色方向和字体方案；有模板时记录模板继承与内容映射策略。
- 是否建议使用用户图片、生成图片、流程图、表格或数据图表。

## 有模板时追加的规划内容

当用户同时提供模板时，规划稿或已提供 plan 的审阅结论还必须覆盖：

- 模板文件路径及其角色：严格使用的模板或仅作视觉参考。
- 模板尺寸、可复用页面/布局与主要视觉特征。
- 每个计划页面如何映射到模板布局或视觉语言。
- 是否基于模板副本生成新文件，并明确不覆盖模板原件。
- 是否需要经用户同意后导出模板预览，用于进一步检查风格。

## 逐页规划要求

逐页内容必须详细到用户可以确认是否忠实、完整、适合展示，并足以作为后续制作的执行契约。用户可以手动修改 plan；后续制作必须以用户确认后的 plan 为准。对每一页提供：

| 字段 | 要求 |
| --- | --- |
| 页码和标题 | 预期出现在页面上的标题 |
| 页面目的 | 该页要解决的问题或承担的叙事任务 |
| 核心结论 | 观众应记住的一句话 |
| 页面具体内容 | 拟放入页面的文字要点、标签、段落、模块、讲解顺序和大体排版，尽量基于原材料 |
| 数据/证据 | 拟使用的数字、图表、案例、引用或原文事实 |
| 公式/符号处理 | 本页涉及的公式、复杂度、上下标、转置、根号、矩阵、变量定义或公式简写；说明使用 Office Math、解释性简写、矢量公式回退，或无需公式 |
| 图片/图形处理 | 使用哪张图片/论文图/截图/reference image；说明原图引用、截图/裁剪、draw.io SVG/PNG、PPT 原生简化、混合版、生成图片，或无需图片 |
| 表格/数据处理 | 是否需要表格、图表、指标卡或补充数据；列出数据来源、单位、取整/简化策略和待补充数据 |
| 视觉形式 | 图文布局、流程图、对比图、时间线、表格、图片、数据图表或留白结构 |
| 素材来源 | 对应原文章节、页码、图表、附件或指定图片目录；无法定位时说明 |
| 论文图/block 处理 | 原图引用、截图/裁剪、PPT 重画/复现、解释性简化重画、或跳过；若需要复现，说明是否还需单独 reference spec |
| 数据图表基准 | 若本页含数值、表格、坐标轴、单位、图例或百分比，列出数据来源、单位、取整/简化策略和是否需读取 `data-chart-table-workflow.md` |
| 必须触发的 reference/workflow | 明确列出后续制作该页必须读取或遵守的文件，例如 `formula-workflow.md`、`reference-image-diagram-recreation.md`、`data-chart-table-workflow.md`、`visual-qa.md`、`template-workflow.md` |
| 风险与待确认项 | 内容缺口、需要压缩、是否需补图、事实待核验等 |

如果原文不支持某页所需内容，不得自行编造；应将该页标为需要补充材料或改写方案。

若某页包含公式、图片复现、论文图裁剪、表格、数据图表或外部来源，但 plan 没有写清楚对应处理方式和必须触发的 reference/workflow，则该 plan 不完整，不得进入 PPT 制作。

## 快速草稿

用户即使要求“快速做个 PPT 草稿”，只要属于基于来源材料生成新的 PPT，仍必须先提供或审阅规划稿并取得确认。快速模式可以：

- 缩短总体分析篇幅。
- 采用紧凑的逐页规划表。
- 减少风格备选方案。

但不得省略逐页核心结论、具体内容、视觉形式、素材来源与待确认项。

## 学术任务提示

仅当材料明显属于论文、预印本、论文分享、文献汇报、学术答辩或其他证据驱动的学术演示时，提示可使用 `nature-paper2ppt` 辅助论文理解、关键证据筛选与叙事规划。

- 如已安装，只说明联合使用价值并询问用户是否启用。
- 如未安装，说明其可选作用并询问是否需要协助安装。
- 不自动安装，不自动改变当前流程。
- 普通文档转 PPT 不主动提示该 skill。
