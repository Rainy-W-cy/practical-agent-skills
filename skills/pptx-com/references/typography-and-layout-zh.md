# 中文与混排排版规则

仅在没有完整模板可继承，或需要修复页面排版时读取本文件。

## 字体优先级

1. 用户明确指定的字体与品牌规范。
2. 模板中已建立的字体体系。
3. 以下默认设置。

| 用途 | 中文 | 英文与数字 |
| --- | --- | --- |
| 标题 | Microsoft YaHei Bold | Times New Roman Bold |
| 正文 | Microsoft YaHei | Times New Roman |
| 图注与来源 | Microsoft YaHei | Times New Roman |
| 代码 | Consolas | Consolas |

如果系统字体或模板渲染存在问题，先说明替代方案，再改用可用字体。

## 字号

| 对象 | 默认范围 |
| --- | ---: |
| 封面标题 | 30-44 pt |
| 页面标题 | 26-36 pt |
| 小节标题 | 20-24 pt |
| 正文 | >= 16 pt |
| 图注与来源 | >= 10-11 pt |
| 关键数字 | 40-64 pt |

当模板字号更成熟且仍具备可读性时，保持模板规范。

## 页面结构

- 每页保留单一主要结论或叙述目标。
- 正文和列表默认左对齐；不要为了形式感大量居中正文。
- 使用稳定的边距、对齐线和内容块间距。
- 避免过长段落；将内容转化为结论、证据和视觉表达。
- 文字密集时优先减少信息或拆页，而不是降低字体。
- 图表、图片与流程图应有明确标题或必要说明。

## 可读性

- 确保正文、图注与背景对比明显。
- 图片上的标注优先使用 PowerPoint 原生文本与线条。
- 不把关键事实文字烘焙在 AI 生成背景图中。
- 在投影或普通笔记本屏幕下仍应容易辨认。
