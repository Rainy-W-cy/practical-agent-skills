# 概述
用于对任意学科的学术论文做系统、正式、可复用的详细解读。输出目标包括：
- 讲清论文的研究问题和语境
- 解释方法、研究设计或理论框架
- 检查证据是否支撑结论
- 指出局限、风险、适用边界与可复现性
- 给出面向不同用途的阅读建议

# 总体要求
## 1. 结果总览优先
开头必须先总结论文最关键的发现、成立条件、证据强度和主要限制，再展开细节。

## 2. 判断必须有证据锚点
每个重要判断尽量落在以下信息上：
- 实验或案例结果
- 图表和统计指标
- 对照组、消融、样本设定
- 公式、定义、框架图、算法步骤
- 结论或附录中的边界说明

若论文没有给出足够支撑，必须明确写出“证据不足”。

## 3. 解释要服务于理解
- 当术语、指标、变量或方法链成为理解论文的门槛时，应解释它们。
- 解释时优先回答：
  - 它是什么
  - 它在本文中做什么
  - 为什么它会影响结论

## 4. 不做学科预设
- 不默认 AI、医学、社科、系统、理论任一类论文天然更可信或更重要。
- 评价标准应随论文类型调整，但核心仍是“问题、方法、证据、边界”。

# 按论文类型调整关注点
## A. 实证 / 实验研究
重点关注：
- 样本或数据来源
- 研究设计、对照与变量控制
- 指标与统计方法
- 结论是否被过度外推

## B. 方法 / 算法 / 模型研究
重点关注：
- 方法主线和关键机制
- 与 baseline 的真实差别
- 改进来源是否清楚
- trade-off 是否被充分呈现

## C. 系统 / 工程 / 实现研究
重点关注：
- 设定是否现实
- 真实成本、收益与依赖条件
- 峰值指标与端到端效果是否区分
- 迁移到其他场景的门槛

## D. 理论 / 概念 / 综述研究
重点关注：
- 命题和概念边界是否清晰
- 推理链条是否自洽
- 文献支撑是否充分
- 是否存在包装性创新

# 输出结构
默认输出以下 13 个部分。除非用户明确要求压缩，否则不要省略核心部分。

## 1. 结果总览
优先回答：
- 论文最关键的发现或主张是什么
- 在什么条件下成立
- 最有力的证据来自哪里
- 主要局限或代价是什么
- 哪些部分目前只能视为作者声称

## 2. 论文定位
说明：
- 所属研究主题
- 论文类型
- 适合放在什么语境下理解

## 3. 背景与问题定义
讲清：
- 为什么会有这个研究问题
- 现有工作主要不足在哪里
- 作者试图补什么空白

## 4. 阅读前必须知道的关键术语 / 概念
列出理解本文最关键的 3 到 8 个术语或概念。
每个术语采用以下结构：
- **术语名**
  - 定义：...
  - 在本文中的作用：...
  - 为什么重要：...

## 5. 核心思想概述
先给正式概括，再给一段必要的通俗解释。回答：
- 研究对象是什么
- 核心机制、研究设计或理论框架是什么
- 作者认为它为什么有效

## 6. 方法、设计或论证链条拆解
根据论文类型展开：
- 方法论文：讲清输入、步骤、关键模块、输出、与 baseline 的差别
- 实证论文：讲清样本、变量、实验流程、对照、分析路径
- 理论论文：讲清定义、命题、推导或论证框架
- 系统论文：讲清模块、流程、依赖、实施条件和成本

必要时补充：
- 哪一步最关键
- 哪一步证据最弱
- 哪一步最依赖作者设定

## 7. 创新点判断
分开说明：
- 作者声称的创新点
- 从当前证据看较可信的创新点

并判断更偏向：
- 新问题定义
- 新方法
- 新研究设计
- 新系统实现
- 工程整合
- 理论梳理
- 主要是已有要素重组

## 8. 证据与实验设置
总结最关键的证据设计：
- 数据、样本、任务或场景
- baseline / 对照组
- 指标或评价口径
- 实验或分析设定

重点检查：
- 对照是否合理
- 证据是否足以支持核心主张
- 是否缺少关键对照或负结果

## 9. 结果解读
解释结果意味着什么，而不是只复述数字或表格。重点回答：
- 哪些结果真正支撑主张
- 哪些结果只是辅助性证据
- 是否存在结论放大、证据不足或解释过度
- 有哪些 trade-off

## 10. 优点
列出最重要的优点，并说明为什么这些优点重要。

## 11. 局限、风险与疑点
必须具体说明：
- 适用范围是否窄
- 假设是否过强
- 证据链是否有缺口
- 是否缺少关键对照、长期验证、外部验证或现实场景验证

## 12. 可复现性 / 可迁移性评估
单独判断：
- 论文是否给出足够细节
- 复现主要难点在哪里
- 方法是否容易迁移到其他数据、场景、人群、系统或任务

## 13. 总体评价与阅读建议
先给正式总结，再按用户目标给建议，例如：
- 做课程汇报重点看哪里
- 做综述重点提炼什么
- 做复现先关注哪些细节
- 做方向了解时哪些局限不能忽略

- 有条件参考
- 谨慎参考
