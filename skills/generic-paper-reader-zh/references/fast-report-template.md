# 概述
用于快速解释一篇学术论文。目标不是覆盖全部细节，而是在较短输出中帮助用户判断：
1. 论文研究了什么
2. 核心结论是什么
3. 这些结论由什么证据支撑
4. 有哪些明显局限或未确认部分
5. 是否值得继续细读

# 处理原则
## 1. 结果先行
开头先说最重要的研究结论、成立条件和主要限制，再讲背景和方法。

## 2. 证据约束
- 没有实验、案例、图表、统计结果或文中明示依据时，不要把作者结论写成已证实事实。
- 如果片段不足，直接写“不足以判断”。

## 3. 通俗但不降级
- 可以做轻量解释，帮助用户快速理解术语或方法。
- 不要为了通俗而改写论文原意，也不要引入文中没有的机制。

## 4. 适配所有学科
- 面向医学、社科、自然科学、工程、算法、系统、理论等不同论文，统一关注“问题、方法、证据、局限、阅读价值”。
- 不预设任何学科专用指标是默认重点，除非论文本身明确如此。

# 输出格式
默认输出以下 8 个部分，顺序固定。

## 1. 一句话总结
用 1 句话交代论文研究对象、核心发现和最主要限制。

## 2. 结果总览
优先用 3 到 5 句回答：
- 论文的关键结论是什么
- 这些结论在什么条件、样本、任务、数据或场景下成立
- 主要证据来自哪里
- 主要代价、局限或不确定性是什么

## 3. 研究问题
说明论文试图解决什么问题，以及为什么这个问题值得研究。

## 4. 核心思路 / 研究设计
根据论文类型选择合适表述：
- 方法论文：核心方法主线是什么
- 实证论文：研究设计或实验设计是什么
- 理论论文：核心命题、框架或推理路径是什么

## 5. 主要贡献
列出 3 点以内主要贡献，并尽量区分：
- 作者声称的贡献
- 从当前证据看较可信的贡献

## 6. 关键证据展开
只展开最重要的 1 到 3 组证据，例如：
- 核心实验
- 关键表格或图示
- 对照组结果
- 样本分析
- 典型案例

说明这些证据支持了什么，以及还不能支持什么。

## 7. 优点
列出 3 条以内最值得肯定的点。

## 8. 局限与疑点 / 是否值得细读
先列出 3 条以内主要局限、疑点或证据缺口，再给出明确判断：
- 值得精读
- 可选择性阅读
- 只需了解主结论
- 暂不值得投入较多时间

判断理由要和用户目标对齐，例如：
- 做课程汇报
- 做综述
- 做选题
- 做复现
- 了解某一方向现状
